# Database Schema

## Invoices & Billing Module

### `invoices` Table
Stores header information for customer invoices.

**Columns:**
- `id`: UUID (PK)
- `workspace_id`: UUID (FK to `workspaces`, required for isolation)
- `customer_id`: UUID (FK to `customers`)
- `appointment_id`: UUID (FK to `appointments`, optional link)
- `invoice_number`: String (Unique per workspace, generated by Service Layer)
- `status`: ENUM (`DRAFT`, `SENT`, `PARTIALLY_PAID`, `PAID`, `OVERDUE`, `CANCELLED`, `REFUNDED`)
- `currency`: String (ISO 4217 Code, Default: USD)
- `subtotal`: Numeric (12,2)
- `discount_amount`: Numeric (12,2)
- `tax_amount`: Numeric (12,2)
- `total_amount`: Numeric (12,2)
- `issue_date`: Timestamp with Time Zone
- `due_date`: Timestamp with Time Zone
- `notes`: Text (Optional)
- `created_at`: Timestamp with Time Zone
- `created_by`: UUID (FK to `profiles`, Optional)
- `updated_at`: Timestamp with Time Zone
- `updated_by`: UUID (FK to `profiles`, Optional)
- `deleted_at`: Timestamp with Time Zone (Soft delete)

**Indexes & Constraints:**
- `UNIQUE idx_invoices_workspace_number`: On `workspace_id, invoice_number` where `deleted_at IS NULL` (Ensures workspace-level uniqueness)
- `idx_invoices_workspace`: On `workspace_id` where `deleted_at IS NULL`
- `idx_invoices_customer`: On `customer_id` where `deleted_at IS NULL`
- `idx_invoices_status`: On `workspace_id, status` where `deleted_at IS NULL`

**Row Level Security (RLS):**
- **View**: Workspace members can view active invoices (`deleted_at IS NULL AND workspace_id IN (...)`).
- **Manage**: Workspace members can manage active invoices (`deleted_at IS NULL AND workspace_id IN (...)`).

---

### `invoice_line_items` Table
Stores individual line items for an invoice.

**Columns:**
- `id`: UUID (PK)
- `invoice_id`: UUID (FK to `invoices`, ON DELETE CASCADE)
- `service_id`: UUID (FK to `services`, optional link)
- `description`: Text (Immutable historical snapshot)
- `quantity`: Integer (Default: 1)
- `unit_price`: Numeric (12,2) (Immutable historical snapshot)
- `discount`: Numeric (12,2) (Immutable historical snapshot)
- `tax_rate`: Numeric (5,2) (Immutable historical snapshot)
- `total`: Numeric (12,2) (Immutable historical snapshot)
- `created_at`: Timestamp with Time Zone
- `created_by`: UUID (FK to `profiles`, Optional)
- `updated_at`: Timestamp with Time Zone
- `updated_by`: UUID (FK to `profiles`, Optional)
- `deleted_at`: Timestamp with Time Zone (Soft delete)

**Indexes:**
- `idx_invoice_line_items_invoice`: On `invoice_id` where `deleted_at IS NULL`

**Row Level Security (RLS):**
- **View**: Workspace members can view active line items if they have access to the parent invoice.
- **Manage**: Workspace members can manage active line items if they have access to the parent invoice.

---

### Constraints & Soft Deletes
- **Soft Deletes**: Uses `deleted_at IS NULL` in queries and RLS policies instead of hard deletion, preserving historical financial records.
- **Workspace Isolation**: All records are strictly bound to `workspace_id` (either directly on `invoices` or implicitly via `invoice_id` on `invoice_line_items`). RLS enforces this boundary at the database level.
- **Invoice Numbering**: Constrained via unique index per workspace. Logic to format invoice numbers (e.g., `GYM-00001`) resides purely in the Service Layer.
- **Immutable Line Items**: When services are billed, their current data is copied into `invoice_line_items`. Subsequent changes to a `Service`'s price do not mutate historical invoices.
- **Monetary Types**: Always stored as `NUMERIC(12,2)` rather than floating-point to prevent rounding errors.
- **Currencies**: Always stored as ISO 4217 (e.g., `USD`, `GBP`). Currency symbols are reserved for the UI Layer.
